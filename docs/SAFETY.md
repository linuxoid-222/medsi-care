# Ограничения безопасности MEDSI Care

MEDSI Care — синтетический исследовательский прототип. Safety-событие не
является диагнозом, медицинским заключением или назначением лечения.

## Правило MVP

Версия правила: `safety-v1`. Событие создаётся только для факта, который:

1. сохранён после подтверждения пользователем;
2. имеет `polarity=present`;
3. относится к одной из явно заданных категорий: `chest_pain`,
   `shortness_of_breath`, `loss_of_consciousness`, `stroke_signs`,
   `severe_bleeding`.

Неподтверждённый текст и ответ LLM сами по себе не создают safety-событие.
Событие содержит исходное evidence, сохраняется в `monitoring_events` и
создаёт уведомление доверенному лицу. Интерфейс показывает консервативную
рекомендацию обратиться за срочной медицинской помощью.

Набор правил предназначен для демонстрации архитектуры и требует отдельной
медицинской и нормативной оценки перед любым реальным использованием.
