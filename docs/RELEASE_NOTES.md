# MEDSI Care v0.1.0-mvp

11 ноября 2026 года. Стабильная версия исследовательского прототипа для
синтетических данных.

## Что доступно

- Владелец профиля может загрузить воспроизводимый сценарий, ввести измерения
  и создать текстовый или голосовой check-in. Замена демосценария сохраняет
  ручные записи и исторические события.
- Браузер записывает речь через MediaRecorder. Локальный faster-whisper
  распознаёт запись, а GigaChat извлекает факты из проверенного текста.
  Факты можно исправить, отклонить или ввести вручную и подтвердить.
- Мониторинг сравнивает дневные измерения с индивидуальным baseline и
  учитывает актуальные подтверждённые факты. События содержат снимок
  оснований. Доверенное лицо видит события и может прочитать уведомления.
- Повтор сохранения открытого транскрипта использует прежний UUID. Если
  ответ потерян, интерфейс объясняет безопасный повтор и поиск записи через
  «Открыть последнюю запись» после перезагрузки.

Повторный анализ сохранил исходный снимок и `read_at`.

[Приёмка 0233065](reviews/acceptance-2026-11-11-mvp-0233065.md) обнаружила
N1–N3. [Повторная приёмка 6ffe7c5](reviews/reacceptance-2026-11-11-mvp-6ffe7c5.md)

[Отчёт исправлений](demo_checks/mvp-acceptance-fixes-2026-11-11.json)

в обоих прогонах относятся к SQL-only вариантам для memory.

[Research-v2](RESEARCH.md) описывает отдельный эксперимент сравнения методов
на синтетических данных. Его архив воспроизводит результаты этого набора.
Проверки приложения подтверждают работу описанных сценариев. Клиническая
эффективность в этих проверках не оценивалась.

## Запуск

Из корня проекта подготовьте зависимости и локальный `.env` по `.env.example`.
Для PostgreSQL в Compose выполните:

```bash
python3 -m venv .venv
.venv/bin/pip install -e 'backend[dev]'
npm --prefix frontend ci
docker compose up -d db
set -a
source .env
set +a
.venv/bin/alembic upgrade head
.venv/bin/alembic check
PYTHONPATH=backend .venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Для существующего PostgreSQL укажите его `DATABASE_URL` и примените миграции
к выбранной базе. Текущая ревизия — `0008_check_in_attempt`. В другом
терминале запустите `npm --prefix frontend run dev -- --host 127.0.0.1`
и откройте `http://127.0.0.1:5173/`. Настройки GigaChat, микрофона и роли
приведены в [инструкции демо](DEMO.md).

## Ограничения

- Демо-роли и один синтетический профиль. Production-аутентификация,
  приглашения, журнал действий и rate limiting не реализованы.
- Качество ASR зависит от записи. GigaChat требует сети и локальных
  credentials. При недоступном извлечении можно подтвердить факты вручную.
- При reload локальный черновик транскрипта теряется. Сохранённая запись
  доступна через «Открыть последнюю запись».
- Baseline и правила событий рассчитаны на демонстрационные данные.
  Прототип не предназначен для клинических решений.
